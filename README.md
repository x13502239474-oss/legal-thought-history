# 法律史与法律思想 · 系统自学平台

一套移动端优先的《法律史与法律思想》系统自学网页。它不是法律新闻站，也不是知识百科，而是以三部经典为理论根基、整合为六部分十八模块的大学课程级学习平台。

## 课程内容

以凯利《西方法律思想简史》为思想史主干、伯尔曼《法律与革命》为制度史主干、罗尔斯《正义论》为现代正义理论核心，整合成逻辑连贯的大学课程。

- **六大部分**：法律与法律思想的基础 / 中世纪法律思想与制度形成 / 近代西方法律思想革命 / 现代法律思想流派 / 现代正义理论 / 法律国家与现代社会
- **十八模块**：每模块含十个知识单元（章节导入、核心概念、历史背景、理论详细讲解、代表人物、理论比较、经典案例、现实联系、学术争论、章节总结）
- **研习工具**：思想家索引、法律学派索引、关键概念索引、历史时间线、理论比较表

## 功能

- 首页课程总览与六部分导航、模块目录
- 手机端可折叠目录、页内目录、上下模块翻页
- 全站内容搜索（覆盖全部讲义正文与索引）
- 表格在手机上横向滚动，正文排版适配长时间阅读
- 西式古典羊皮卷视觉风格

## 技术

纯静态站点（HTML + CSS + JavaScript），无后端、无第三方依赖。数据驱动：课程结构与正文位于 `js/data/`，渲染逻辑位于 `js/app.js`，样式位于 `css/style.css`。可直接双击 `index.html` 离线打开。

课程正文为独立编写的学习讲义，忠实原著思想但用自己的话重组，引用术语注明出处；有争议的观点标注不同解释，不把一说当定论。
